# تکنولوژی در آموزش — ارائهٔ وب برای Vercel

این پروژه **ارائهٔ اسلایدی وب** است، نه فایل .pptx. تمام متن‌ها فارسی و راست‌به‌چپ‌اند. صفحهٔ شروع (اسلاید ۰)، ۱۶ اسلاید محتوایی، یادداشت ارائه‌دهنده، منابع هر اسلاید و کنترل‌های ارائه آماده‌اند.

## مشاهدهٔ فوری

فایل `presentation.html` را با مرورگر باز کنید؛ فونت، تصویر، استایل و اسکریپت در همان فایل قرار دارند. برای اجرای ارائه و فیلم اینترنت لازم نیست؛ فقط باز کردن لینک منابع نیاز به اینترنت دارد. قابلیت تمام‌صفحه ممکن است در بعضی پیش‌نمایش‌ها یا مرورگرهای موبایل محدود باشد.

## دیپلوی روی Vercel

### روش پیشنهادی: GitHub

1. فایل ZIP را استخراج کنید.
2. **محتویات پوشهٔ پروژه** (جایی که `package.json` و `vercel.json` هستند) را در یک مخزن GitHub قرار دهید؛ پوشهٔ `node_modules` لازم نیست.
3. در Vercel یک پروژهٔ جدید بسازید و مخزن را Import کنید.
4. Framework Preset را **Other** انتخاب کنید. تنظیمات زیر در `vercel.json` موجودند:
   - Install Command: `npm ci`
   - Build Command: `npm run build`
   - Output Directory: `public`
   - Root Directory: ریشهٔ پروژه، جایی که package.json است.
5. Deploy را بزنید. پروژه به متغیر محیطی، دیتابیس یا کلید API نیاز ندارد.

این بسته آمادهٔ دیپلوی است؛ از طرف شما روی حساب Vercel منتشر نشده است.

راهنمای رسمی: https://vercel.com/docs/builds/configure-a-build

### روش جایگزین: CLI

Node.js 22 یا جدیدتر نصب باشد. داخل پوشهٔ پروژه:

```bash
npm ci
npm run build
npx vercel
# پس از بررسی پیش‌نمایش:
npx vercel --prod
```

ورود به Vercel و انتخاب پروژه را خودتان در جریان رسمی CLI انجام دهید.

## اجرای محلی

```bash
npm ci
npm run build
npm run dev
```

نشانی پیش‌فرض: `http://localhost:4173`. برای توقف، Ctrl+C بزنید.

## صفحهٔ شروع و کنترل‌ها

سایت ابتدا صفحهٔ سلام را نمایش می‌دهد. فقط با دکمهٔ **ورود به ارائه** وارد اسلایدها می‌شوید؛ پیکان‌ها و Space از صفحهٔ سلام عبور نمی‌کنند. نشان کتاب در نوار کنار ارائه، شما را به صفحهٔ شروع برمی‌گرداند و با ورود دوباره می‌توانید از همان اسلاید ادامه بدهید. لینک مستقیم اسلاید هم ابتدا صفحهٔ شروع را نشان می‌دهد و بعد از زدن دکمه، اسلاید مورد نظر باز می‌شود.

دکمه‌های پایین از جریان محتوا جدا و به فضای نمایش متصل‌اند؛ اسکرول یا بلند شدن اسلاید ۴ و سایر اسلایدها جای آن‌ها را تغییر نمی‌دهد.

- پیکان چپ، Space یا PageDown: اسلاید بعدی
- پیکان راست یا PageUp: اسلاید قبلی
- Home / End: اولین / آخرین اسلاید
- O: نقشهٔ اسلایدها
- N: یادداشت ارائه‌دهنده
- F: تمام‌صفحه
- Esc: بستن پنجره / خروج از تمام‌صفحه
- گوشی: حرکت افقی به راست برای اسلاید بعدی؛ اسکرول عمودی برای خواندن ادامهٔ اسلاید
- در صفحه‌کلید فارسی، برای میانبرهای حروف، زبان کیبورد را انگلیسی کنید؛ دکمه‌های روی سایت مستقل از زبان کیبورد کار می‌کنند.

یادداشت‌ها روی همین نمایشگر در پنجره باز می‌شوند؛ پنجرهٔ مستقل برای مانیتور دوم وجود ندارد. اگر روی پروژکتور نمایش می‌دهید، یادداشت‌ها را از `CONTENT-FA.md` روی دستگاه دیگری بخوانید.

## محتوای ارائه

از چاپ، رادیو و تلویزیون تا PLATO، اینترنت، موبایل، MOOC، آموزش ترکیبی و AI؛ سپس کاربردها، نمونهٔ طرح درس علوم، دسترسی‌پذیری، حریم خصوصی، چارچوب یونسکو و جمع‌بندی.

حدود ۱۸ تا ۲۰ دقیقه برای توضیح اسلایدها + حدود ۱۵ دقیقه برای فیلم و گفت‌وگو. متن کوتاهِ اسلایدها در `web/slides.ts` و توضیح شفاهی در فیلد `note` هر اسلاید قرار دارد. نسخهٔ خواندنی در `CONTENT-FA.md` است.

## فیلم و زیرنویس فارسی — نسخهٔ کامل

فیلم ارسالی شما در `public/assets/film.mp4` قرار گرفته و داخل اسلاید ۱۳ پخش می‌شود. نسخهٔ ارسالی حدود **۱۳:۱۸** است (با نسخهٔ CBS با مدت ۱۳:۳۱ تفاوت دارد)، وضوح آن **۱۲۸۰×۷۲۰** و کدک‌ها H.264/AAC هستند. ویدیو دوباره فشرده نشده؛ فقط برای شروع سریع پخش، ساختار MP4 به fast-start تبدیل شده است.

تمام ۳۳۷ بخش فایل زیرنویس دوزبانه بررسی و ترجمهٔ فارسی با متن انگلیسی آن تطبیق داده شد. نام‌ها، اصطلاحات و ترجمه‌های تحت‌اللفظی اصلاح شدند و جمله‌های خردشده برای خواندن روان‌تر در ۱۷۷ بخش بازچینی شده‌اند. بازبینی بر اساس متن انگلیسیِ تشخیص خودکار و زمینهٔ گزارش است؛ این خروجی رونوشت کلمه‌به‌کلمهٔ مستقل از صوت یا ترجمهٔ رسمی CBS نیست. چند عبارت بریدهٔ میان نماها همچنان با سه‌نقطه مشخص‌اند. زمان شروع و پایان از زیرنویس ارسالی حفظ شده؛ قسمت‌های مجاور گاهی ادغام شده‌اند.

- `public/assets/khanmigo-fa.srt`: زیرنویس فارسی اصلاح‌شده برای پخش‌کننده‌های دیگر
- `public/assets/khanmigo-fa.vtt`: نسخهٔ سازگار با وب
- `web/captions.ts`: همان زیرنویس برای پخش داخل سایت

زیرنویس به‌صورت TextTrack استاندارد در مرورگر ساخته می‌شود؛ بنابراین برای نمایش آن درخواست جداگانه یا CDN لازم نیست و در نسخهٔ آفلاین هم کار می‌کند. دکمهٔ «زیرنویس فارسی: روشن/خاموش» و کنترل زیرنویس پخش‌کننده در دسترس‌اند. فیلم خودکار شروع نمی‌شود. خروج از اسلاید یا باز کردن پنجره‌ها فیلم را متوقف می‌کند و زمان پخش برای بازگشت به اسلاید حفظ می‌شود.

در اسلاید فیلم، Space پخش/توقف می‌کند؛ پیکان‌های چپ/راست پنج ثانیه عقب/جلو می‌روند. کنترل‌های قبلی/بعدی پایین و PageUp/PageDown همچنان اسلاید را عوض می‌کنند. وقتی خودِ پخش‌کننده فوکوس دارد، میانبرهای آن به مرورگر سپرده می‌شوند.

### اجرای آفلاین بدون نصب

ZIP را **کامل استخراج کنید** و فایل `presentation.html` در ریشهٔ پروژه را با Chrome یا Edge باز کنید. فایل HTML و پوشهٔ `public` باید کنار هم بمانند. فونت، عکس و زیرنویس در HTML هستند؛ فیلم از `public/assets/film.mp4` خوانده می‌شود. انتقال فقط فایل HTML کافی نیست. در بعضی مرورگرهای موبایل، دسترسی به فایل‌های همسایه محدود است؛ در آن حالت نسخهٔ Vercel یا اجرای محلی استفاده شود.

### اجرای محلی یا Vercel

فایل ویدیو به‌همراه پروژه منتشر می‌شود و نیازی به iframe یا میزبان دیگر نیست. اگر بعداً خواستید از میزبانی خارجی استفاده کنید، نشانی مستقیم MP4 را در `web/app.ts` عوض کنید. iframe پلتفرم دیگر معمولاً اجازهٔ استفاده از زیرنویس محلی این پروژه را نمی‌دهد.

منبع اثر: CBS / 60 Minutes. فایل ویدیو را خودتان برای این پروژه فراهم کرده‌اید؛ پیش از انتشار عمومی، حق نشر و شرایط استفادهٔ صاحب اثر را بررسی کنید. ساخت این بسته به معنی دریافت مجوز انتشار عمومی یا دیپلوی روی حساب شما نیست.

## انتخاب فناوری

**TypeScript + HTML/CSS + esbuild**، با خروجی استاتیک و بدون بک‌اند.

- TypeScript برای محتوای ساختاریافته و تعاملات مرورگر مناسب است.
- یک ارائهٔ اسلایدی به سرور برنامه، دیتابیس یا Rust نیاز ندارد.
- Rust می‌تواند برای پردازش سنگین یا سرویس سرور مفید باشد، اما در این پروژه مشکل واقعی را حل نمی‌کند و هزینهٔ نگهداری اضافه می‌کند.
- React/Next.js هم ممکن بودند، ولی برای این سایت تک‌صفحه‌ای ضروری نیستند. Vercel خروجی استاتیک را سرو می‌کند.

## Material 3 Expressive و Morph

این یک پیاده‌سازی سفارشی وب بر پایهٔ مشخصات Material است؛ کتابخانهٔ رسمی Expressive برای Compose نیست و گواهی رسمی انطباق ندارد.

- رنگ‌های معنایی `--md-sys-color-*` با **SchemeExpressive** از بستهٔ رسمی Material Color Utilities تولید می‌شوند.
- چهار seed، حالت روشن/تیره/سیستم و سه سطح کنتراست وجود دارد. seed رنگ ورودی است؛ SchemeExpressive ممکن است رنگ primary را با چرخش hue متفاوت تولید کند.
- شکل‌ها و گوشه‌ها از توکن‌های Material و فواصل عمده از مقیاس ۸ پیکسلی استفاده می‌کنند.
- فونت فارسیِ محلی **Vazirmatn** برای خوانایی و پوشش فارسی جایگزین عمدی Roboto شده است؛ سلسله‌مراتب Display / Headline / Title / Body / Label حفظ شده است.
- سطوح تونال، دکمه‌های Filled/Tonal، Navigation Rail و Dialog از توکن‌ها استفاده می‌کنند؛ سایه‌های سنگین به‌کار نرفته‌اند.
- **View Transitions API** موقعیت و اندازهٔ عنوان، قاب اصلی و عناصر مشترک را بین اسلایدها درون‌یابی می‌کند؛ معادل وبِ Morph، نه ترنزیشن اختصاصی PowerPoint.
- منحنی فضایی پیش‌فرض وب: `cubic-bezier(.38,1.21,.22,1)` با ۵۰۰ میلی‌ثانیه؛ افکت opacity با `cubic-bezier(.34,.80,.34,1)` و ۲۰۰ میلی‌ثانیه. این‌ها تقریب‌های spring از راهنمای رسمی وب‌اند، نه شبیه‌ساز فیزیکی کامل spring.
- اگر مرورگر View Transitions را نداشته باشد، ورود سادهٔ اسلاید با fade/translation استفاده می‌شود؛ Morph کامل تضمین نمی‌شود.
- ترجیح سیستمی `prefers-reduced-motion` و تنظیم کاربر رعایت می‌شود.

مشخصات حرکت: https://m3.material.io/styles/motion/overview/specs

## ویرایش

- `web/slides.ts`: متن، یادداشت، زمان پیشنهادی و منابع
- `web/app.ts`: کنترل‌ها، پنجره‌ها، تم و ترنزیشن‌ها
- `public/style.css`: طرح، توکن‌ها و واکنش‌گرایی
- `public/assets/`: فونت و تصویر محلی
- `build.mjs`: ساخت JavaScript و نسخهٔ HTML مستقل
- `vercel.json`: تنظیمات مقصد دیپلوی **Vercel**

بعد از هر ویرایش `npm run build` را اجرا کنید تا `public/app.js` و `presentation.html` به‌روز شوند. فایل ساخته‌شدهٔ app.js را به‌جای کد منبع ویرایش نکنید.

## بررسی انجام‌شده

- ساخت و type-check موفق
- بررسی چیدمان ۱۶ اسلاید در عرض‌های ۱۴۴۰، ۱۲۸۰، ۹۰۰ و ۳۹۰ پیکسل
- بدون اسکرول افقی یا overflow متنی در تست‌های انجام‌شده؛ در موبایل اسکرول عمودی عمدی است
- کنترل کیبورد، انتخاب اسلاید، یادداشت‌ها، منابع، تغییر تم و کاهش حرکت بررسی شده‌اند
- همهٔ ۱۶ اسلاید در دسکتاپ و حالت‌های منتخب موبایل، پنجره‌ها و تم تیره به‌صورت تصویری بازبینی شده‌اند
- جفت‌رنگ‌های متن/پس‌زمینهٔ معنایی در ۴ seed × ۲ حالت × ۳ سطح کنتراست بررسی شدند؛ کمترین نسبت در تست از ۵٫۱ بیشتر بود. این بررسی محدود به این جفت‌رنگ‌هاست، نه گواهی جامع WCAG.
- خروجی روی حساب Vercel شما تست یا منتشر نشده است.

## منابع و مجوزها

منابع آموزشی و لینک‌های آن‌ها در آخرین اسلاید و `CONTENT-FA.md` هستند. در فایل `THIRD-PARTY.md` مجوز فونت، بستهٔ Material و منشأ تصویر آمده است. پروژه هیچ دادهٔ آموزشیِ شخصی جمع نمی‌کند؛ فقط ترجیح ظاهر در localStorage همان مرورگر ذخیره می‌شود.

## بررسی نسخهٔ فیلم‌دار

پخش فایل 720p، فعال شدن زیرنویس، روشن/خاموش کردن آن، توقف با Space، جلو بردن با پیکان، توقف هنگام خروج از اسلاید، حفظ موقعیت پخش و ثابت ماندن دکمه‌های اسلاید در Chromium بررسی شدند. پخش آفلاین از HTML همراه پوشهٔ public هم آزمایش شد. زیرنویس فارسی جداست و روی تصویر چسبانده نشده؛ کیفیت فیلم اصلی حفظ شده است.
